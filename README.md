# Weihnachtshaus 2026

Abstimmungsseite für die Familie: 17 Ferienhäuser für Weihnachten, jede:r bewertet mit Top / Passt / Lieber nicht.

- Statische Seite (`index.html`, Fotos in `img/`), gehostet über GitHub Pages.
- Stimmen liegen in Supabase (Projekt `weihnachtshaus`), Zugriff nur über die Funktionen `wh_get_votes` und `wh_save_vote`, die das Familienpasswort prüfen. Das Passwort steht nicht im Repo.
